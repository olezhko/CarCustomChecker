# CarCustomChecker
Неофициальное приложение для проверки машин на БЕЛТАМОЖСЕРВИС

## Что нового

### Трекинг деклараций
- Вкладка «Отслеживание» переименована в «Трекинг» и разделена на две: «VIN» и «Декларации».
- В «Декларациях» можно сохранить номер таможенной декларации (выбрав ВПТО) и следить за её статусом: зарегистрирована, выпуск разрешён, отказано в выпуске или выставлено требование.
- Для каждой декларации показываются вид, дата регистрации, номер разрешения, а также причина отказа или текст требования, если они есть.

### Новая вкладка «РПТО»
- Список региональных пунктов таможенного оформления с адресами, режимом работы и телефонами.
- Очередь транспортных средств на каждом пункте: время постановки в очередь и приёма из очереди, поиск по номеру ТС.

### Новая вкладка «СВХ»
- Список складов временного хранения по таможням с адресами, режимом работы и телефонами.
- Записи о транспорте на складе: время въезда и выезда, разрешение на процедуру ВХ, документы.

### Улучшения
- Исправлена прокрутка длинных списков: при подгрузке следующей страницы список больше не сбрасывается в начало.
- Обновление списков потягиванием вниз больше не отправляет лишние повторные запросы.
